# GrubDay2026Plando

A companion mod for the 2026 Grub-A-Thon


To play this plando:

* Install this mod
* From "Plando Files" choose either the Marathon version (the one that was on stream) or Extended version (harder version, stricter logic, skips are harder)
* On Lumafly, click "Open Saves Folder"
* Ensure that if you have an Architect directory there, its empty
* Drag the contents of the version you chose (should be ICDL folder, Architect Folder, and a single JSON) into the saves directory
* Launch the game
* If everything worked correctly, after choosing "Past Randos" and loading into Grubday 2026, regardless of which start you pick, you shoul see a zote skull next to you
* (The skull is there to verify you have the architect files, it is not used for any skip but you are welcome to try)
